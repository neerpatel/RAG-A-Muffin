Gmail Label Filter
Comma-separated label IDs to sync (e.g. INBOX, SENT, STARRED). Defaults to INBOX and SENT when blank.
Local Directories
Container paths to scan and index on each sync. Directories must be bind-mounted into the container.
Obsidian Vaults
Container paths to your Obsidian vault(s). Must be bind-mounted. Markdown files are parsed with frontmatter and wikilinks resolved.
YouTube Videos
YouTube video URLs to index via auto-generated transcripts. Videos without captions will be skipped.
GitHub Repositories
Index READMEs and issues from GitHub repos (owner/repo). Add a personal access token below for private repos.
Browser Bookmarks
Path to an exported Chrome/Firefox bookmarks HTML file (Netscape format). Each bookmark URL will be scraped and indexed.
Active Connectors
Disable a connector to skip it during sync. The index keeps existing documents.

Before embedding, the LLM rewrites your question into a precise, keyword-rich search query. Improves recall for vague or conversational phrasing at the cost of a short extra LLM call.
